# Guía de Assets para Portafolio

Deposita aquí los recursos correspondientes para tu portafolio:

- `assets/images/`: 
  - Mockups de proyectos (`editorial-1.jpg`, `branding-1.jpg`, `empaques-1.jpg`, etc.)
  - Fotografía de perfil / portada (`perfil.png`, `jana-book.png`)
- `assets/videos/`: 
  - Video Reel principal (`showreel.mp4` o `reel.webm`)
- `assets/fonts/`: 
  - Archivos locales de tipografía si los tienes en .woff2 / .ttf (ej. Satoshi, Space Mono)
- `assets/icons/`: 
  - Íconos SVG personalizados o logos adicionales.
